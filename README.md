# API Automation Testing

Этот проект содержит набор тестов для автоматического тестирования API с использованием библиотеки `pytest` и отчётности через `allure`.

## Описание

Проект реализует тесты для различных операций с сущностями через API, включая создание, получение, обновление и удаление сущностей. Каждый тест сопровождается подробным описанием шагов и отчетами с использованием библиотеки `allure`.

## Структура проекта

- **`api/`**:
    - **`base_request.py`**: Базовый класс для выполнения HTTP-запросов с использованием библиотеки `requests`.
    - **`data.py`**: Содержит данные для создания и обновления сущностей, такие как `CREATE_ENTITY_DATA` и `UPDATE_ENTITY_DATA`.

- **`helpers/`**:
    - **`api_helper.py`**: Вспомогательные функции для работы с API, включая создание, обновление, удаление сущностей и другие операции.

- **`tests/`**:
    - **`test_api.py`**: Тесты для различных операций с API, таких как создание, обновление, удаление сущностей.
    - **`conftest.py`**: Фикстуры для тестов, настройки тестового окружения, подключения и очистки данных.
- **`requirements.txt`**: Список зависимостей, необходимых для проекта.
- **`README.md`**: Документация по проекту, инструкции по установке и запуску тестов.

## Установка

Для установки зависимостей выполните команду:

```bash
  pip install -r requirements.txt
```

### Клонирование репозитория
```bash
  git clone https://github.com/ваш-репозиторий.git
  cd simbirsoft_sdet_project
```
### Установка зависимостей
```bash
  pip install -r requirements.txt
```
### Собрать и запустить контейнеры
```bash
  docker-compose up --build -d
```
### Или через Makefile:
```bash
  make run
```
### Обычный запуск тестов
```bash
  pytest tests/test_api.py
```
### Параллельный запуск тестов с отчетом Allure
```bash
  allure serve allure-results
```
